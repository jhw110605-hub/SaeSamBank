# 새삼은행 (Saesam Bank)

친구들끼리 "누가 누구에게 얼마를 정산해야 하는지" 기록하는 **정산 장부** 앱입니다.
Kivy로 만들었고, PC와 안드로이드 모두에서 돌아갑니다.

> ⚠️ 이 앱은 **실제 돈을 옮기지 않습니다.** 정산 요청을 기록하고,
> 실제 이체는 카카오페이/토스/은행 앱으로 직접 한 뒤 앱에서 "완료 처리"만 누르는 구조예요.
> (돈을 직접 옮기는 서비스는 전자금융업 등록이 필요해서 개인이 만들 수 없습니다.)

## 사용 흐름
1. **계좌 개설** — 이름, PIN, (선택) 실제 은행명/계좌번호 입력 → 앱 계좌번호(110-xxxxxx) 발급
2. **정산 요청하기** — 상대방 이름(또는 계좌번호) + 금액 + 메모 → 요청 생성
3. **정산 대기 목록** — "계좌 복사"를 누르면 요청 문구가 복사돼요. 카톡/문자에 붙여넣어 보내세요.
4. 상대가 실제로 이체하면 **"완료 처리"** 를 눌러 정산 끝!
5. 홈 화면에서 **받을 돈 / 보낼 돈** 합계를 한눈에 확인

## 구성 파일
- `main.py` — 앱 진입점, 화면 로직
- `storage.py` — SQLite 저장소 (계좌, 정산 기록)
- `saesambank.kv` — 화면 레이아웃
- `fonts/NotoSansKR-Subset.ttf` — 한글 폰트
- `buildozer.spec` — 안드로이드 APK 빌드 설정

## PC에서 실행
```
pip install kivy
python main.py
```

## 안드로이드 폰에 설치 (GitHub로 APK 만들기, 윈도우 OK)
1. github.com 가입 → 우측 상단 `+` → **New repository** → 이름 `saesam-bank` → Create
2. 만들어진 저장소 화면에서 **uploading an existing file** 클릭
3. 이 폴더 안의 **모든 파일과 폴더(.github 폴더 포함)** 를 끌어다 놓고 **Commit changes**
4. 위쪽 **Actions** 탭 → 왼쪽 **APK 빌드** → **Run workflow**
5. 20~40분 기다리면 초록 체크 표시 → 그 실행을 눌러 맨 아래 **saesambank-apk** 다운로드
6. 압축을 풀면 `.apk` 파일이 있어요 → 폰으로 옮겨서 설치 (설정에서 "출처를 알 수 없는 앱 설치 허용" 필요)

(리눅스가 있다면 `pip install buildozer cython` 후 `buildozer android debug` 로 직접 빌드해도 돼요.)

## 알아둘 점
- 데이터는 각자 기기의 `saesambank.db` 파일에만 저장돼요. 즉, **친구 폰의 앱과는 자동으로 연동되지 않습니다.**
  여러 명이 같은 장부를 공유하려면 서버(예: Firebase) 연동이 필요해요.
